# Changelog

## 0.1.0

- Three skins, Amber Phosphor, LCARS Deck and Neon Command, each turned on by its `dark-pulse-*` theme: fonts, shapes, tabs, panel headers and decoration across Tern and every plugin.
- A skin toggle in the top bar (AMBER / LCARS / NEON / OFF) and matching palette commands. OFF returns to the last non-PULSE dark theme.
- The first start installs the themes into omp's themes folder and the fonts into `~/Library/Fonts`.
